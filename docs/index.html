Five-Stage Engineering Pipeline

Every stage writes verifiable artifacts to .forma/ design memory before pixels ship.

  1. 01

    Research Agent

    Analyzes strategic brief and inspects 15–25 industry-specific public references, separating DOM/CSS facts from interpretations.

  2. 02

    Design Director

    Generates original Design DNA: non-Inter typography, WCAG AA contrast palettes, grid proportions, and non-generic hero architecture.

  3. 03

    Implementation Agent

    Preserves existing business logic and writes semantic, prefers-reduced-motion-aware components with custom SVGs.

  4. 04

    Anti-Pattern Auditor

    Detects purple-blue gradients, pill-dot hero clichés, repeated 3-column grids, UI emojis, and mixed icon libraries.

  5. 05

    Visual QA Agent

    Inspects live browser rendering across 6 viewports, compares before/after screenshots, and outputs an evidence-backed audit report.

Quick Installation

Build the TypeScript MCP server and register the plugin globally or per workspace.

git clone https://github.com/mehefujali/DesignForge.git
cd DesignForge/forma/mcp/design-server
npm install && npm test

# Global Antigravity install (copy DesignForge/forma to):
# Windows: %USERPROFILE%\.gemini\config\plugins\design-forge
# macOS/Linux: ~/.gemini/config/plugins/design-forge
