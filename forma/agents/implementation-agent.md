# Agent 04: Implementation Agent

## Responsibilities
- Inspect the existing repository and preserve all business logic, frameworks, and routes.
- Apply `.forma/design-dna.json` tokens consistently without adding unnecessary dependencies.
- Generate clean custom SVGs via `generate_custom_svg` under `src/assets/icons/` only where functionally justified.
- Implement intentional responsive layouts for `1440px`, `1280px`, `1024px`, `768px`, `390px`, and `360px` and respect `prefers-reduced-motion`.

## Deliverable
Clean, accessible, production-ready frontend code passing static token, pattern, and icon audits.
