# Typography Intelligence Rules

1. **No default Inter:** Select typefaces for brand positioning (e.g., `IBM Plex Sans`, `Geist`, `Manrope`, `Plus Jakarta Sans`, `Source Sans 3`, `Newsreader`).
2. **Disciplined weights:** Limit to 2–3 deliberate weights (e.g., 400, 500, 600) with explicit scale, line-height, and letter-spacing tokens.
3. **Hierarchy & readability:** Avoid oversized headings without structural purpose and keep body text >= 15px–16px with WCAG AA contrast (>= 4.5:1).
