# Core Design Principles

1. **Every decision requires a reason:** Optimize for visual hierarchy, brand differentiation, information architecture, typography, layout precision, usability, and industry relevance — never decoration volume.
2. **Original identity:** Never copy Apple, Stripe, Microsoft, Linear, Vercel, or any reference site. Extract principles, then build a project-specific Design DNA.
3. **Research before pixels:** Complete `project_analyze`, `research_references`, and `extract_design_patterns` before generating visual code.
4. **Design Memory:** Store approved references, Design DNA, exceptions, and audit history in `.forma/`. Do not reuse another project's identity blindly.
